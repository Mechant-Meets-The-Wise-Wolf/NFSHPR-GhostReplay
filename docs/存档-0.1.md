## 6. 从存档复现构建

```powershell
Set-Location -LiteralPath 'E:\DevTools-LoushShinny\Projects\HPRGhostReplay'
.\native\Build.ps1      # 需要 research/native-ghost-prototype 下的 Zig 与 MinHook
.\Build.ps1             # 输出 app/HPRGhostReplay.exe
.\Build.ps1 -Configuration Development   # 输出 app/HPRGhostReplay-dev.exe
```

`research/` 不入库，所以在新的克隆上原生构建会缺少编译器。仓库保证源码可读、C# 主程序可构建；原生重建需另外取得 Zig 0.13 与 MinHook 1.3.4（`native/Build.ps1` 支持 `-ZigPath`）。
