HPRGhost 0.1.1 兼容测试版 — 2026-10-14

一、安装

将本压缩包的全部内容解压到 NFS11Remastered.exe 所在的游戏根目录。
不要再套一层 HPRGhost 文件夹，也不要单独移动 EXE。
安装完成后结构应为：

游戏目录\NFS11Remastered.exe                 （朋友自己的游戏）
游戏目录\StartHPRGhost.cmd                   （本包）
游戏目录\mod-research\ghost-system\HPRGhost.exe
游戏目录\mod-research\ghost-system\events.tsv
游戏目录\mod-research\ghost-system\vehicles.tsv
游戏目录\mod-research\ghost-system\recordings\

已有旧版时，先关闭旧工具，再覆盖本包中的同名程序文件。
本包不包含个人录像；已有 recordings 文件不会因本包而删除。
本工具无需安装 ASI Loader 或 ZMenu，不需要额外插件。

二、环境与版本

Windows 10/11 64 位；使用系统 .NET Framework 4.x。
游戏请使用窗口或无边框模式，独占全屏下车影覆盖可能不可见。
本版取消固定 EXE 哈希白名单。游戏文件 SHA256 只用于记录来源，不再作为连接或导入录像的准入条件。
兼容依据是运行中的车辆、相机等关键代码与数据结构是否符合已适配的 PC x64 布局。
不同 EXE 文件、不同发行来源，只要关键结构相同，工具就会尝试连接。
当前仍要求实际进程名为 NFS11Remastered，并保留车辆/相机/计时器的结构和数值检查。

如果提示“运行时结构尚未匹配”，请先进入游戏主菜单，等待工具重试。
若始终不匹配，请将 mod-research\ghost-system\compatibility.log 发给开发者，
同时说明屏幕上的错误和游戏状态；这个版本仍可能需要单独适配。
检查未通过时不会直接使用未知内存布局。
不同 EXE 哈希的录像可以导入，但双方仍需相同的赛事 ID 和赛事资源。

注意：取消哈希拒绝已经通过回归检查，但尚未在朋友的实际游戏 EXE 上完成连接验证。

本包不包含游戏 EXE、模型、贴图或赛事修改包。
模型从朋友自己的 VEHICLES 与 SHADERS.BNDL 读取。
互发录像需要相同赛事 ID 和赛事资源；自定义赛事需要双方安装相同赛事包。
例如 [ONLINE] CHARGED ATTACK 等改为单人的赛事，不会因安装幽灵工具而自动出现。
本测试版按正常单人赛事流程验证；其他玩法仍需测试。

三、录制自己的整场赛事

1. 双击 StartHPRGhost.cmd 打开工具，只运行一个工具实例。
2. 启动游戏，先停在选赛菜单，确认工具已连接。
3. 保持勾选“自动录制整场赛事”，填写“录制者”名称。
4. 正常进入赛事并完成冲线，不需要按录制键或在开场暂停。
5. 新文件自动保存在 mod-research\ghost-system\recordings。
6. 将生成的 .hprghost 文件发送给朋友即可；不需要发送游戏车辆模型。

退出、中途重开、切换赛事会丢弃未完成录制。
工具在比赛中途才启动时，会等待下一次完整发车。

四、跟跑朋友的车影

1. 在工具中点击“导入高手文件”，选择朋友发来的 .hprghost 文件。
   或将文件放入 recordings，点击“刷新文件列表”后选中它。
2. 点击“选择并等待自动播放”，保持勾选“启用所选车影”。
3. 从选赛菜单正常进入文件对应的同一赛事，车影会自动对齐播放。
4. 新录制会自动记住车型，显示相应的真实车身和轮胎网格。
5. “车影不透明度”默认 45%，可在 10% 至 85% 调整。
6. 仅跟跑时可以取消“自动录制整场赛事”。

版本 2 的旧整场文件未记录可靠车型，需在“旧文件车型”中明确选择当时的车。
版本 3 的旧文件可读，但可能已经被旧版按成绩截短；缺失尾段不能补回，需要重新录制。
版本 1 的手动录制缺少完整赛事信息，不支持自动匹配。
本版新文件格式为版本 4，轨迹时长与比赛成绩分别保存；双方建议使用本版。

五、当前效果与限制

显示的是游戏本地真实车辆几何，使用简化材质与透明度。
尚未接入完整贴图、完整车漆效果、车轮转向/旋转动画、车辆损伤动画。
没有场景深度遮挡，建筑物和其他车辆不会挡住车影。
没有行车路线、实时落后时间或碰撞。
暂不保存其他插件自定义的车身和轮胎混搭。

六、测试反馈与停止

反馈时请提供：游戏 EXE 的 SHA256、赛事名称/ID、录制文件、问题发生的比赛时间，
以及“车影消失 / 位置不对 / 工具未连接”等具体现象。
如需日志，可附工具目录中的 automatic.log 与 race-transitions.log；请先查看其中内容。
日志只写在本地，不会自动上传或发送。
如果提示访问游戏失败，请让工具与游戏使用相同的运行权限。

关闭工具窗口即可停止。若要移除，先备份自己的 recordings，再移除本包的文件。
本包通过只读权限读取游戏进程和资源，不修改现有游戏插件、车辆包或赛事包。
