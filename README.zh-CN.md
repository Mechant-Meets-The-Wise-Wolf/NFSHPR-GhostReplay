## 使用与发行目录

发行版解压得到清晰的 HPRGhostReplay 文件夹，直接运行 HPRGhostReplay.exe，无需放进游戏目录。优先识别运行中的游戏；“选择游戏”可指定 NFS11Remastered.exe 并保存位置。名称表与原生回放组件内嵌 EXE，不需要额外 TSV、Python、SDK 或 C++ 运行库。软件启动自动识别运行进程、历史路径及Steam游戏库，立即安装缺少的回放插件和内嵌官方x64加载器；无需先选择录像或联网。已有加载器不替换。仅录制不需要加载器。使用系统 .NET Framework 4.x，面向 Windows 10/11 x64。

录像在 EXE 旁的 Recordings，界面“打开录像文件夹”直达。正常运行不写日志，仅故障时写入 Logs/errors.log；记住的游戏路径写入 GameFolder.txt。升级保留 Recordings 和 GameFolder.txt。老开发目录中的录像不会自动移动或删除，可复制或导入到发行版。

完整使用说明见 packaging/使用说明.txt，变更见 packaging/更新说明.txt。原开发说明已备份至 research/before-portable-release-20261016/README.zh-CN.md；其中旧路径和旧版本号仅属历史。

## 界面与行为

录制、回放每次启动默认关闭。开启录制后发车自动录完整场，冲线后保存；重开或退出丢弃未完成录像。录制、回放独立开关，可同时运行。已开启的卡片在就绪、等待和运行时整体变亮，关闭及未导入时为灰色。

录像库标题旁集中放置打开文件夹、载入回放、导入、刷新。启动时不自动载入；未载入显示“未导入”。计时使用分:秒.厘秒。录像时长取轨迹 Duration，不冒充未经结算页核实的正式成绩。

重命名只改文件名；导入保留原件；删除需确认且限制在录像库。新录像默认记录人 LoughShinny302，可编辑，旧录像的记录人和内容不改动。

## 构建与打包

Build.ps1 使用系统 .NET Framework C# x64 编译器，默认 Configuration=Release，输出 app/HPRGhostReplay.exe；-OutputName 可指定候选文件。-Configuration Development 输出本地 app/HPRGhostReplay-dev.exe，包含自检和探针。Package.ps1 会拒绝开发构建。src/AppPaths.cs 的 AppInfo 是版本号来源；游戏目录由 GameLocation 解析，车辆模型不再依赖程序相对源码的位置。

Build.ps1 将 native/bin/HPRGhostNative.asi 嵌入 EXE，原生源码更新时先运行 native/Build.ps1；开发构建工具不进入发行包。Package.ps1 以白名单打包 EXE、使用说明和第三方许可，创建空 Recordings。输出位于项目内 releases，附 ZIP SHA256。不会打包录像、日志、配置、源码、研究样本、游戏资源或第三方插件。发行无需启动脚本；启动入口为 app/StartHPRGhost.cmd；游戏根目录的旧入口已迁出。

## beta.5 发行构建精简

正常发行只包含核心录制、回放与界面。DevelopmentTools.cs、SamplingDiagnostics.cs、TimingDiagnostics.cs、DevelopmentLog.cs、SelfTests.cs、ModelChecks.cs、UiTests.cs、LogTests.cs、ReleaseLogTests.cs 不编入发行 EXE。DEVELOPMENT 条件下才编入采样计数器、模拟输入分支、模型预览和截图导出。

逐次采样不再累加调试计数，不再在快照上保留冗余的赛事引用、竞争者索引、车辆索引或未使用的赛事调试字段。FrameFence 的稳定候选、重复观察次数、毫秒级采样和时钟/摄像机一致性检查仍参与正常功能，不属于调试输出；保留它们以防止旧抖动复发。

默认没有 APP_STARTED、连接、录制、回放或保存等正常状态日志写入，相关调用在 Release 编译时消除。只有真正故障才写 Logs/errors.log，最多 16 KiB，内容限版本和固定错误码，第一次新故障替换上一次运行的故障报告。没有日期、路径、地址、PID、哈希、录像名称或署名。

启动只清理 Logs 内旧 automatic.log、compatibility.log、race-transitions.log、diagnostic-error.txt、status.log；不动录像、配置、其他文件或研究资料。GameFolder.txt 和录像本身继续保留正常业务数据，不属于错误报告。

验证：118 项开发检查；发行 EXE 的模块/字段剔除检查；相同合成输入的发行/开发 FrameFence 输出完全一致；六份旧录像读写后字节一致；只读采样实际游戏且不创建 Logs 或 research。发行版不支持开发命令，返回码 2；开发版保留它们。并未重新跑完整赛事或证明帧率提升。

## beta.8 原生回放整合

主界面直接传递所选录像、实际车型和不透明度。游戏内组件每次 Present 使用当前赛事时钟插值绘制；不再创建 WPF 透明窗口，不需要原型控制器，不增加平滑补偿。自动录制和录像格式不变。原生组件不创建游戏车辆实体，不参与碰撞、AI 或物理。

模型与录像通过有界共享内存传递，后台线程校验并加载；渲染回调不读文件、不解析资源。独立深度预绘制解决远侧轮胎和车身叠层；命令执行恢复游戏绘制状态。关闭回放、退出主工具、心跳超时或切出游戏时停止绘制。

首次载入回放时将内嵌组件安装到已识别的游戏目录；游戏运行期间延后更新，退出后才替换已知旧版组件。未知同名文件不覆盖。现有 ASI 加载器和第三方插件保留。只录制不触发组件安装。

测试用户反馈：修正自身遮挡后“恢复正常，操作流畅”；录像回放“比原来流畅太多了，操作也不卡”；主界面整合后“我测试了，很正常，包括别的录像”。没有把 Present 调用率当作实际显示帧率或键盘延迟测量。

## beta.9 离线自动安装与卸载

首次载入录像时检查游戏根目录的已有加载器。识别到可用的 x64 Ultimate ASI Loader 则保留；缺少时在游戏退出后安装内嵌的官方9.7.4 x64 dinput8.dll，与 HPRGhostNative.asi 配合，重启游戏一次生效。仅录制不触发安装。未知同名DLL、错误架构或未知安装标记均提示处理，不静默覆盖。已识别的其他代理入口也会复用，避免重复加载器。

主界面下方新增“回放组件 / Playback setup”。卸载前必须退出游戏，默认只移除与当前内嵌版本哈希一致的 HPRGhostNative.asi。加载器默认保留，其他ASI插件可能依赖它；仅本软件新安装、具有 HPRGhost-loader.sha256 归属标记且文件内容未改变的加载器允许勾选移除。原有加载器、改动文件、录像、配置及其他插件均保留。卸载成功后清除主界面回放选择与待安装状态，不会立刻自动装回；之后主动载入录像才重新安装。

官方下载包 SHA256 e5860e7d9a1805267535b65749575b5e406cc6ea3325c7392189c578815045d1，与GitHub资产digest一致。内嵌DLL SHA256 031A3E5576D91DCE1E438D36B9A3D462C7334AB4791990A8FF1E3DDC0E132DAF，运行时校验哈希与x64架构。原文件、官方发行元数据及MIT许可保留在 native/vendor/ultimate-asi-loader-9.7.4；许可随正式包提供。

174项开发检查通过，覆盖新装/复用/同名冲突/游戏运行中延后/卸载保护/双语卸载弹窗及原有功能。隔离临时游戏目录完成安装与卸载测试；当前实机已有6.5.0加载器保持不动，没有把新版加载器的离线检查描述为新的局内验证。beta8原生回放的用户实测结论保持有效，绘制组件本身未改动。

## beta.11 卡片启用态

录制与回放每次启动都关闭。用户开启后，卡片在就绪、等待、运行时保持亮色；关闭或回放未导入时灰色。ActivityCard分开保存真实运行态IsRunning与视觉启用态IsLit，避免把就绪亮色误用为“正在录制/回放”的判断或日志。手动载入回放继续作为开启该份录像的明确操作。

190项离线检查通过，确认初始关闭、就绪双卡片亮起、两个开关互不影响及未导入仍灰色。ui-ready-bright.png已查看，文字与布局完整。安装与绘制流程未改动。
